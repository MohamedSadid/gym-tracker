# Exercise muscle region map

Use this atlas when painting how-to stills. Visual source: `content/exercises/_character/muscle-map.jpg`.

Chart colors are **labels only**. On lift stills, paint primary `#B8F000` (~90%) and auxiliary `#D4E88A` (~40%). Stay inside the region for that ID. Do not flood neighboring IDs.

When a highlight request names IDs, paint **only those IDs**.

## Letter prefixes

| Letter | Group |
|--------|--------|
| **C** | Chest |
| **A** | Abs |
| **O** | Obliques |
| **B** | Biceps, back (lats / lower back), triceps |
| **D** | Deltoid |
| **F** | Forearm |
| **H** | Hip flexors (front) / hamstrings (back) |
| **Q** | Quadriceps |
| **G** | Glutes |
| **S** | Calves |
| **T** | Traps / tibialis / Achilles tendon |
| **N** | Neck |

## Deltoids (D)

| ID | Name | Notes |
|----|------|--------|
| **D1** | Front / anterior delt | Front legend: Deltoid (front) |
| **D3** | Side / lateral delt | On the front figure at the outer shoulder. Not in the original legend; treat as **lateral delt**, not rear. |
| **D2** | Rear / posterior delt | Back legend: Deltoid (rear) |
| **D4** | Upper trapezius | Front figure at the neck/shoulder junction. **Same as back T1.** Not in the original legend. |

## IDs that share a code (do not mix them up)

| Code | Front | Back |
|------|--------|------|
| **T1** | Tibialis anterior (shin) | Trapezius upper (or say **D4**) |
| **F2** | Forearm flexors | Forearm extensors |
| **H1** / **H2** | Hip flexors | Hamstrings |

## How to ask for a highlight

Name the IDs and the role, e.g. primary `C1 C2 D1`, auxiliary `B5`. Paint only those regions on the lift stills. Leave every other ID gray.
